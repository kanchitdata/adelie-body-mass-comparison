การทดสอบการแจกแจงปกติ

\[ \begin{aligned} H_0 &: \text{น้ำหนักตัวของเพนกวิน Adelie ทุกกลุ่มย่อยมีการแจกแจงปกติ} \\ H_1 &: \text{น้ำหนักตัวของเพนกวิน Adelie มีอย่างน้อย 1 กลุ่มที่การแจกแจงไม่เป็นแบบปกติ} \end{aligned} \]

การทดสอบความเท่ากันของความแปรปรวน

การทดสอบความเท่ากันของความแปรปรวนของ body_mass_g ระหว่างตัวผู้และตัวเมียในเกาะเดียวกันในแต่ละเกาะด้วย F-test

กำหนดระดับนัยสำคัญ 0.05

\[ \begin{aligned} % เกาะ Torgersen H_{01} &: \sigma^2_{\text{ผู้, Torgersen}} = \sigma^2_{\text{เมีย, Torgersen}} \\ H_{11} &: \sigma^2_{\text{ผู้, Torgersen}} \neq \sigma^2_{\text{เมีย, Torgersen}} \\[1ex] % เกาะ Dream H_{02} &: \sigma^2_{\text{ผู้, Dream}} = \sigma^2_{\text{เมีย, Dream}} \\ H_{12} &: \sigma^2_{\text{ผู้, Dream}} \neq \sigma^2_{\text{เมีย, Dream}} \\[1ex] % เกาะ Biscoe H_{03} &: \sigma^2_{\text{ผู้, Biscoe}} = \sigma^2_{\text{เมีย, Biscoe}} \\ H_{13} &: \sigma^2_{\text{ผู้, Biscoe}} \neq \sigma^2_{\text{เมีย, Biscoe}} \end{aligned} \]

Code 
ftest.mf <- function(isl) {
  return(
    adelie %>%
      filter(island == isl) %>%
      {
        var.test(body_mass_g ~ sex, data = .)
      } %>%
      tidy()
  )
}

c(Torgersen = "Torgersen", Dream = "Dream", Biscoe = "Biscoe") %>%
  map_dfr(ftest.mf, .id = "island") %>%
  select(-c(method, conf.low, conf.high, alternative)) %>%
  select(island, everything()) %>%
  gt()

จากการทดสอบความแปรปรวนเท่ากันด้วย F-test ที่ระดับความสำคัญทางสถิติ \(\alpha = 0.05\) พบว่า เกาะ Torgersen และเกาะ Biscoe มี \(p\)-value มากกว่า \(0.05\) ในขณะที่เกาะ Dream มี \(p\)-value น้อยกว่า \(0.05\)

จึงทำการตัดสินใจ:

  • ไม่ปฏิเสธ \(H_{01}\) และ \(H_{03}\) สำหรับเกาะ Torgersen และ Biscoe ตามลำดับ สรุปได้ว่าความแปรปรวนของน้ำหนักตัว (\(body\_mass\_g\)) ระหว่างเพศผู้และเพศเมียในสองเกาะนี้ไม่แตกต่างกัน

  • ปฏิเสธ \(H_{02}\) สำหรับเกาะ Dream สรุปได้ว่าความแปรปรวนของน้ำหนักตัว (\(body\_mass\_g\)) ระหว่างเพศผู้และเพศเมียในเกาะ Dream มีความแตกต่างกัน อย่างมีนัยสำคัญทางสถิติ

ข้อสรุปภาพรวม: ความแปรปรวนของน้ำหนักตัวเพนกวินสายพันธุ์ Adelie ระหว่างเพศผู้และเพศเมียมีความแตกต่างกันอย่างน้อย 1 เกาะ ซึ่งก็คือ เกาะ Dream


การทดสอบความเท่ากันของความแปรปรวน body_mass_g เพศผู้ในแต่ละเกาะด้วยวิธีการ Levene-test

กำหนดระดับนัยสำคัญ 0.05

\[ \begin{aligned} H_0 &: \sigma^2_{\text{ตัวผู้, Torgersen}} = \sigma^2_{\text{ตัวผู้, Dream}} = \sigma^2_{\text{ตัวผู้, Biscoe}} \\ H_1 &: \text{มีอย่างน้อย 1 กลุ่มที่แตกต่างกัน} \end{aligned} \]

การทดสอบค่าเฉลี่ยของน้ำหนักตัว

  • ก่อนเปรียบเทียบค่าเฉลี่ยระหว่างเกาะ จะตรวจสอบก่อนว่าเพศผู้และเพศเมียมีค่าเฉลี่ยต่างกันหรือไม่ ถ้าไม่ต่างกัน จะรวมสองเพศเปรียบเทียบพร้อมกัน แต่ถ้าต่างกัน จะเปรียบเทียบระหว่างเกาะโดยแยกตามเพศ

จากการทดสอบการแจกแจงปกติและความเท่ากันของความแปรปรวนทำให้เรารู้ว่า

  • การแจกแจงของทุกกลุ่มมีการแจกแจงปกติ (Table 2)

  • ความแปรปรวนของ body_mass_g ในเพศผู้แต่คนละเกาะเท่ากันในทั้ง 3 เกาะ (Table 4) แต่สำหรับความแปรปรวน body_mass_g เพศเมีย ในแต่ละเกาะมีอย่างน้อย 1 เกาะที่ความแปรปรวนไม่เท่ากัน (Table 5)


การทดสอบความเท่ากันของค่าเฉลี่ยระหว่างเพนกวินเพศผู้และเพนกวินเพศเมียในเกาะเดียวกัน

  • การแจกแจงของทุกกลุ่มที่จะนำมาเปรียบเทียบเป็นการแจกแจงปกติ (Table 2)

  • ความเท่ากันของความแปรปรวนระหว่างเพนกวินเพศผู้และเพศเมียในเกาะเดียวกันมีความแปรปรวนเท่ากันยกเว้นเกาะ Dream ที่มีความแปรปรวนไม่เท่ากันระหว่างเพนกวินเพศผู้และเพศเมีย (Table 3)

สำหรับวิธีการเปรียบเทียบค่าเฉลี่ย

  • t-test ความแปรปรวนเท่ากันสำหรับเกาะ Torgersen และ Biscoe

  • t-test ความแปรปรวนไม่เท่ากันสำหรับเกาะ Dream


การทดสอบความเท่ากันของค่าเฉลี่ย body_mass_g ระหว่างเพศผู้และเพศเมียในเกาะเดียวกัน

\[ \begin{aligned} % เกาะ Torgersen (var.equal = TRUE) H_{01} &: \mu_{\text{ผู้, Torgersen}} = \mu_{\text{เมีย, Torgersen}} \\ H_{11} &: \mu_{\text{ผู้, Torgersen}} \neq \mu_{\text{เมีย, Torgersen}} \\[1ex] % เกาะ Biscoe (var.equal = TRUE) H_{02} &: \mu_{\text{ผู้, Biscoe}} = \mu_{\text{เมีย, Biscoe}} \\ H_{12} &: \mu_{\text{ผู้, Biscoe}} \neq \mu_{\text{เมีย, Biscoe}} \\[1ex] % เกาะ Dream (var.equal = FALSE) H_{03} &: \mu_{\text{ผู้, Dream}} = \mu_{\text{เมีย, Dream}} \\ H_{13} &: \mu_{\text{ผู้, Dream}} \neq \mu_{\text{เมีย, Dream}} \end{aligned} \]

Code 
t.test.mf <- function(isl, var.e = F) {
  male.m <- adelie %>%
    filter(island == isl, sex == 'male') %>%
    pull(body_mass_g)

  female.m <- adelie %>%
    filter(island == isl, sex == "female") %>%
    pull(body_mass_g)

  result <- t.test(
    male.m,
    female.m,
    var.equal = var.e,
    alternative = "two.sided"
  ) %>%
    tidy()

  return(result)
}


map2_dfr(
  .x = c("Torgersen", "Biscoe", "Dream"),
  .y = c(T, T, F),
  .f = t.test.mf
) %>%
  select(-c(conf.low, conf.high)) %>%
  mutate(
    island = c("Torgersen", "Biscoe", "Dream"),
    p.value = pvalue(p.value)
  ) %>%
  select(island, everything()) %>%
  gt()

การทดสอบสมมติฐานหลัก

การทดสอบความเท่ากันของค่าเฉลี่ย body_mass_g ระหว่างเกาะ


สำหรับวิธีการทดสอบความเท่ากันของค่าเฉลี่ยน body_mass_g เพนกวินสายพันธุ์ Adelie จะใช้เป็น One-way ANOVA ความแปรปรวนเท่ากันสำหรับเพศผู้ และ Welch’s ANOVA ความแปรปรวนไม่เท่ากันสำหรับเพศเมีย ทั้งคู่กำหนดระดับนัยสำคัญ 0.05 ทั้งคู่

\[\begin{aligned} H_0 &: \mu_{ตัวผู้, Torgersen}=\mu_{ตัวผู้, Dream}=\mu_{ตัวผู้ , Biscoe}\\ H_1 &: \text{ มีอย่างน้อย 1 กลุ่มที่แตกต่างกัน} \end{aligned}\]

สรุปผลการวิจัย

จากการวิเคราะห์น้ำหนักตัว (body_mass_g) ของเพนกวินสายพันธู์ Adelie บนเกาะ Torgersen, Dream และ Biscoe โดยเปรียบเทียบเฉพาะเพศเดียวกัน (เพราะพบว่าเพศผู้และเพศเมียมีค่าเฉลี่ยต่างกันในทุกเกาะ) พบว่า

  • เพศผู้ One-way Anova ได้ p-value = 0.989 ซึ่งมากกว่า 0.05 จึงไม่ปฏิเสธ \(H_0\) สรุปว่าค่าเฉลี่ยน้ำหนักระหว่างเกาะไม่แตกต่างกัน
  • เพศเมีย: Welch’s ANOVA ได้ p-value = 0.747 ซึ่งมากกว่า 0.05 จึงไม่ปฏิเสธ \(H_0\) สรุปว่าค่าเฉลี่ยน้ำหนักตัวระหว่างเกาะไม่แตกต่างกัน

ข้อสรุป: ที่ระดับนัยสำคัญ 0.05 ไม่พบความแตกต่างของน้ำหนักตัวเพนกวินสายพันธุ์ Adelie ระหว่างเกาะ Torgersen, Dream และ Biscoe ทั้งในเพศผู้และเพศเมีย
